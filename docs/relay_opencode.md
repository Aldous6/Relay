En Windows, haz doble clic en **Abrir Relay.cmd** en la carpeta del proyecto. El chat se abre en tu navegador. Deja abierta la ventana de Relay mientras lo usas y ciérrala para detener el servidor. También puedes abrirlo desde PowerShell con `.\Start-Relay.ps1 -OpenChat`.

Abre **Ajustes** en la parte superior y elige la carpeta de trabajo. Escribe una tarea o pulsa una sugerencia para preparar un borrador que puedas editar. Relay consulta el catálogo de OpenCode, elige un modelo y muestra su respuesta en la conversación. En los ajustes puedes limitar los modelos disponibles o activar **Confirmar modelo antes de enviar**. El historial se guarda en tu equipo por carpeta. Puedes retomar conversaciones en la barra lateral y buscarlas por título desde el historial. La selección usa reglas cuya calidad y ahorro por tarea aceptada están pendientes de medir.

Relay recuerda los filtros y la confirmación por carpeta. Para usar todos los modelos gratuitos de Zen, elige el proveedor `opencode`, activa **Solo modelos gratuitos** y deja desmarcado **Limitar a mis modelos**. En los ajustes puedes ver la lista para esa carpeta. Relay vuelve a consultar el catálogo antes de enviar, de modo que los modelos se incorporan o salen cuando cambian sus tarifas o su disponibilidad. Con **Confirmar modelo antes de enviar** puedes aceptar la propuesta de Relay o elegir otro en **Modelo para este mensaje**. La elección manual dura un turno. Si todos los proveedores seleccionados están en pausa, la vista previa sigue disponible.

En una instalación nueva, usa OpenCode v2 para los modelos gratuitos. En Windows, Relay busca primero su copia de v2 en `%LOCALAPPDATA%\Relay\opencode-v2` y después el ejecutable instalado en el sistema. El ZIP de Windows incluye el frontend Next.js compilado. Para abrirlo necesitas Python 3.12 o posterior. Para obtener respuestas, configura en tu equipo un proveedor accesible desde OpenCode. [Instalación de OpenCode](https://opencode.ai/docs/) y [soporte del acceso gratuito](https://github.com/anomalyco/opencode/issues/59387).

OpenCode recibe el prompt con el modelo elegido para ese turno y trabaja en la carpeta indicada. Sus herramientas pueden leer o modificar el proyecto según los permisos configurados. Relay usa la CLI en modo no interactivo y conserva las restricciones de OpenCode. Los agentes auxiliares pueden tener sus propios modelos configurados. Si el proveedor rechaza la petición, Relay guarda el error. [Automatización con la CLI](https://opencode.ai/docs/cli/) y [modelos de los agentes](https://opencode.ai/docs/agents/).

Si un proveedor devuelve un 401 que Relay puede atribuir al modelo elegido, Relay lo pone en pausa para esa carpeta. Abre el chat que falló y pulsa **Revisar reintento** y confirma el modelo para volver a enviar el mensaje original. Tus filtros siguen vigentes y el historial conserva ambos intentos con sus consumos respectivos. Para volver a usar Zen, escribe `/connect` en OpenCode, selecciona **OpenCode Zen** e introduce una clave vigente allí. Después pulsa **Volver a habilitar OpenCode Zen** en los ajustes de Relay. [Conexión de OpenCode Zen](https://dev.opencode.ai/docs/zen).

Que un modelo aparezca en el catálogo indica que OpenCode lo anuncia. El acceso efectivo depende de las credenciales, el plan y la cuota del proveedor. OpenCode puede mostrar una tarifa de cero cuando le falta el precio. Para comprobar un cargo de tu cuenta, consulta el registro del proveedor. [Catálogo de OpenCode](https://github.com/anomalyco/opencode/blob/v1.16.2/packages/opencode/src/cli/cmd/models.ts#L24-L45) y [tratamiento de tarifas ausentes](https://github.com/anomalyco/opencode/blob/v1.16.2/packages/opencode/src/provider/provider.ts#L1060-L1068).

Relay muestra el texto, las herramientas finalizadas y el consumo que OpenCode comunica para la sesión principal. Si la salida de la CLI llega incompleta, Relay busca la sesión local que creó para ese envío y comprueba su carpeta, su modelo y su prompt antes de recuperar el resultado. Esta lectura evita volver a enviar el prompt. El consumo visible puede ser parcial si hay subagentes o si un fallo interrumpe la sesión. El gasto exacto permanece desconocido hasta que pueda verificarse con el proveedor. Para comprobar una reparación, revisa los cambios y el resultado de las pruebas del proyecto. [Eventos de la sesión principal](https://github.com/anomalyco/opencode/blob/v1.16.2/packages/opencode/src/cli/cmd/run.ts#L615-L679).

Para desarrollar necesitas Node.js 20.9 o posterior y Python 3.12 o posterior. Desde la raíz del repositorio, `npm ci` instala las dependencias fijadas en el lock. Después, `npm run dev` inicia Next.js y la API Python local. Abre `http://127.0.0.1:3000`. Los cambios en la interfaz se recargan en el navegador. Al modificar el backend Python, reinicia el comando. Si el puerto está ocupado, usa por ejemplo `npm run dev -- --port 3401`. Ctrl+C detiene ambos procesos. [Requisitos de Next.js](https://nextjs.org/docs/pages/getting-started/installation).

Para preparar la distribución, ejecuta `npm run build --workspace relay-workspace` desde la raíz. Next.js escribe las páginas estáticas en `web/out`. El servidor Python de Relay sirve esos archivos y la API en el mismo puerto. [Exportaciones estáticas de Next.js](https://nextjs.org/docs/pages/guides/static-exports).
